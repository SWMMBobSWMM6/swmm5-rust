      The plugin and the wire it talks on

      RustGIS loads a plugin as a WebAssembly module with exactly three functions to call (call, result, log), no files, no clock and a fuel budget. This page plays RustGIS's side of that interface in JavaScript, so what runs here is the module RustGIS runs, byte for byte.

      Install it in RustGIS

      1. Web app. Open web.rustgis.app, start from the World Atlas sample (a tool needs at least one layer on the map), then drag the .rgplugin onto the map or use Plugins › Plugin Manager › Install from a file. A SWMM5 Rust tab appears.
      2. Desktop app. The same Plugin Manager, or drop the file on the window.
      3. Command line.
      Inside a Claude artifact the viewer only saves files with listed extensions, so the package is offered as swmm5-rust-0.1.0.rgplugin.zip: remove .zip from the name before installing. Opened from a web server or your disk, the button saves the .rgplugin directly.
