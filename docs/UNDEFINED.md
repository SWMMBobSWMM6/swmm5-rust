# Where EPA's C is undefined, and what swmm5-rust does

Collected by `tools/ub_sites.py` from the translation's own comments: every place a translator noted that the C reads past an array, follows a NULL pointer, reads an uninitialized value, or is otherwise undefined. Safe Rust cannot do any of these, so each site says what the engine does instead. Most cannot be reached by a valid input file.
